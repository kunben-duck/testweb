# 智能工作台任务字段说明（原始需求版）

## 任务级

| 层级 | 字段 | 数据来源 | 是否必填 | 规格说明 |
| --- | --- | --- | --- | --- |
| 任务级 | 语言环境 | 产品传入 | 是 | 区分中英文<br />中文、英文 |
|  | 模块或APPNAME | 产品传入 | 是 | 展示给用户看的类别。最高层级类别，以区分不同来源的任务。如不同应用（APPID）<br />规则：分类同名或同ID的任务归属1个L1分类下 |
|  | 任务类别 | 产品传入 | 否 | 在L1分类下的L2分类，展示某业务能力往下的更细分的活动类别<br />L2分类，该类别本质是1个数据源，如账务场景下，L2分类包含计划/差异等，不同L2分类扩展字段不同，意味着是不同数据接入源<br />还有一种设计考虑：支持扩展字段可自定义到顶层筛选<br />点击不同的任务类别，可筛选出对应类别下的任务数据 |
|  | **L3**分类 | 产品传入 | 否 | 扩展更多分类<br />在与L2并行的分类，多个分类筛选，则取交集分类；<br />还有一种设计考虑：支持扩展字段可自定义到顶层筛选 |
|  | 标签 | 产品传入 | 否 | 需要有固定格式，如何区分独立的标签（重名的视为同一个标签） |
|  | 任务编码 | 产品传入 | 否 | 用于给用户提供业务含义的任务编码，类似于US单号之类的，每个产品业务规则不同 |
|  | 任务名称 | 产品传入 | 是 | 人机协作的任务名称；用户可点击任务名称进入任务详情<br />不超过300字 |
|  | **任务**ID | EX生成 | 不涉及 | 全局唯一任务ID值，生成后需传给领域Agent。领域Agent与EX交互采用统一的任务ID |
|  | 任务描述 | 产品传入 | 否 | 文本类，对应任务描述和说明，不超过1000字 |
|  | 任务状态 | 产品传入 | 是 | 统一状态值，提供事件规则，由产品统一提供任务状态信息<br />状态值：待处理、处理中、已暂停、需人工处理、已终止、异常、已完成<br /> |
|  | 任务状态说明 | 产品传入 | 否 | 针对当前任务状态，提供简要说明。支持在文字中带跳转链接如打开人机交互卡片/SaaS页面<br />场景举例：如异常时，提示异常说明；需人工处理时，提示如已经到了xxx领导审批 |
|  | 任务责任人 | 产品传入 | 是 | 任务唯一责任人<br />权限：责任人可以操作任务的全部操作 |
|  | 任务参与人 | 产品传入 | 否 | 任务协同人<br />权限：可查看任务进展，可跟随人工介入卡片权限进行人工介入，不允许操作任务级操作（暂停，终止，删除），可通过对话进行任务干预实现改变步骤等。 |
|  | 责任Agent名称 | 产品传入 | 是 | 唯一主责Agent，可能是领域Agent，可能是superAgent<br />先支持单Agent，若后续新增多Agent场景，则需要SuperAgent来编排了 |
|  | 责任AgentID | 产品传入 | 是 | 用户不可见，与admin集成过来的唯一ID保持一致 |
|  | 协作Agent名称 | 产品传入 | 否 | 协作Agent，1个任务需要多个Agent协作完成的场景，此时可能时SuperAgent编排多个领域Agent，可能时领域Agent编排多个子Agent |
|  | 协作AgentID | 产品传入 | 否 | 用户不可见，与admin集成过来的唯一ID保持一致 |
|  | 当前执行Agent名称 | 产品传入 | 是 | 当前正在执行任务的Agent名称，一般来说与责任Agent一致，若涉及多Agent协同且正在执行，则展示多个Agent |
|  | 当前执行AgentID | 产品传入 | 是 | 用户不可见，与admin集成过来的唯一ID保持一致 |
|  | 推荐Skill名称 | 产品传入 | 否 | 该任务应该由哪个Skill来完成，展示的责任Agent名称为SuperAgent，执行Agent为SuperAgent。可支持多个Skill |
|  | 推荐SkillID | 产品传入 | 否 | 用户不可见，与admin集成过来的唯一ID保持一致，支持多个Skill ID |
|  | 任务上下文 | 产品传入？<br />人工介入信息？ |  | 一段Agent执行任务除了已有任务信息之外，还要再补充的任务上下文信息 |
|  | 来源产品名称 | 产品传入 | 是 | 创建任务的产品名称 |
|  | 来源产品APPID | 产品传入 | 是 | EAMAP的产品ID，能找到这个任务归属的应用服务/模块 |
|  | **Agent**执行状态 | 产品传入 | 是 | 系统内部值，不在前台展示？以SE设计的机机交互状态为准 |
|  | 业务扩展字段 | 产品传入 | 否 | 支持字段扩展；支持不同类型字段（文本、时间、数字等）；支持定义字段操作（筛选，模糊搜索，，排序）<br /><br />举例：税务：主体、税种、税期<br />对账：客户、签约主体、合同号、发票号等 |
|  | 执行进度 | EX生成 | 不涉及 | 统计规则：如果有任务步骤，则按已完成步骤/总步骤数；如果没有任务步骤，则不展示 |
|  | 任务进展简述 | 产品传入 | 否 | 任务级别的进展说明，文本型，不超过1000字 |
|  | 创建者 | 产品传入 | 是 | 用户对话创建任务时，创建者为用户；如果是产品自动船舰的，则体现产品名 |
|  | 创建时间 | EX生成 | 不涉及 | 任务创建时间，自动生成 |
|  | 开始时间（计划） | 产品传入 | 否 | 任务计划什么时候开始，可精确到分钟YYYY-MM-DD-HH-MM，可以展示日、小时、分钟，传到什么程度就展示到什么程度 |
|  | 截止时间（计划） | 产品传入 | 否 | 任务计划什么时候要完成，可精确到分钟YYYY-MM-DD-HH-MM，可以展示日、小时、分钟，传到什么程度就展示到什么程度 |
|  | 剩余时间 | EX生成 | 不涉及 | 按当前时间和截止时间计算SLA，展示规则：<br />超过1天，展示xx天xx小时<br />小于1天，展示xx小时xx分钟<br />小于1小时，展示xx分组xx秒 |
|  | 执行过程 | 产品传入 | 是 | 若没有步骤，则在任务层级展示执行过程。<br />执行过程包括：思考过程，调用的工具，结果正文。思维链中需增加ASK USER的结果体现（卡片上填的信息） |
|  | 完成时间 | EX生成 | 是 | 任务改为已完成状态的时间，未完成时体现为“不涉及” |
|  | 开始执行时间 | EX生成 | 不涉及 | 首次启动时间 |
|  | 已执行时长 | EX生成 | 不涉及 | 已运行时长（从首次启动执行时间到当前时间累计） |

## 任务步骤

| 层级 | 字段 | 数据来源 | 是否必填 | 规格说明 |
| --- | --- | --- | --- | --- |
| 任务步骤 | 步骤分组名称 | 产品传入 | 否 | 任务下的步骤分组名称，可按分组折叠或展开步骤，分组也有顺序，可看到分组下的已执行步骤数量/步骤数量，不超过100字 |
|  | 步骤分组顺序 | 产品传入 | 否 | 步骤分组顺序，支持按顺序展示步骤分组 |
|  | 步骤分组ID | 产品传入 | 是 | 步骤分组ID，唯一ID |
|  | 步骤名称 | 产品传入 | 是 | 任务下的步骤名称，不超过100字 |
|  | 所属步骤分组 | 产品传入 | 否 | 步骤归属哪个分组 |
|  | 步骤ID | 产品传入 | 是 | 步骤ID，唯一ID |
|  | 步骤顺序 | 产品传入 | 是 | 步骤顺序，支持按顺序展示步骤 |
|  | 步骤描述 | 产品传入 | 否 | 步骤描述信息，说明这个步骤，给用户更多说明信息 |
|  | 当前步骤 | EX生成 | 不涉及 | 通过状态可以看到当前步骤，（待人工处理/处理中/异常都属于当前步骤）<br />并行场景多 |
|  | 步骤渲染内容 | 产品传入 | 否 | 提供可渲染内容链接，如SaaS页面、自定义卡片 |
|  | 步骤状态 | 产品传入 | 是 | 统一状态值，提供事件规则，由产品统一提供步骤状态信息<br />待处理、处理中、已暂停（预留）、需人工处理、已终止（预留）、异常、已完成、已跳过 |
|  | 步骤状态说明 | 产品传入 | 否 | 针对当前步骤状态，提供简要说明。支持在文字中带跳转链接如打开人机交互卡片/SaaS页面<br />场景举例：如异常时，提示异常说明；需人工处理时，提示如已经到了xxx领导审批 |
|  | [步骤执行过程](https://wiki.huawei.com/domains/168708/wiki/349920/WIKI2026032510545276) | 产品传入 | 是 | 步骤级别，每个步骤有一个执行过程<br />执行过程包括：思考过程，调用的工具，结果正文。思维链中需增加ASK USER的结果体现（卡片上填的信息）<br />单独按钮 |
|  | 开始执行时间 | EX生成 | 不涉及 | 首次启动执行时间 |
|  | 完成时间 | EX生成 | 不涉及 | 步骤改为已完成状态的时间 |
|  | 计划开始时间 | 产品传入 | 否 | 步骤计划什么时候开始，可精确到分钟YYYY-MM-DD-HH-MM，可以展示日、小时、分钟，传到什么程度就展示到什么程度 |
|  | 计划截止时间 | 产品传入 | 否 | 步骤计划什么时候应该完成，可精确到分钟YYYY-MM-DD-HH-MM，可以展示日、小时、分钟，传到什么程度就展示到什么程度 |
|  | 剩余时间 | EX生成 | 不涉及 | 按当前时间和截止时间计算SLA，展示规则：<br />超过1天，展示xx天xx小时<br />小于1天，展示xx小时xx分钟<br />小于1小时，展示xx分组xx秒 |
|  | 累计执行时长 | EX生成 | 不涉及 | 已运行时长（从首次启动执行时间到当前时间累计） |
